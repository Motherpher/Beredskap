# Beredskap – Heby under ytan

**Huvudrapport:** *Heby under ytan – perspektiv på översvämningen 2023*  
**Artikel:** *Ett elverks tragedi – vilken chans till överlevnad hade Heby reningsverks elcentral, sett över 120 år?*  
**Status:** Forskningsdesign och initialt källregister publicerade; ingen slutlig sak- eller ansvarsprövning genomförd.

## Vad som undersöks
Kommunal riskkunskap, institutionellt minne, teknisk sårbarhet och civilsamhällets roll i fredstida kriser. **Före–under–efter** är tidsstrukturen; **logisk/praktisk närhet** är en begreppslig analys; **behov/nyckelbehov/nyckelnyttor** är designens ömsesidiga analysobjekt. Start 2000–2026, relevant historik från 1900.
