# Ett elverks tragedi – Heby 2023

**Research repository starter v1.0 | 20 november 2026**

**Research object:** Heby avloppsreningsverks elcentral, dess placering och funktionsberoende, inom Heby kommun och Örsundaåns hydrologiska system. Det är **inte** ett dricksvattenverk eller ett elproducerande kraftverk.

**Fråga:** Vilka möjligheter fanns före 2 september 2023 att identifiera, minska eller undvika det funktionsbortfall som följde när stigande vatten hotade reningsverkets elcentral?
