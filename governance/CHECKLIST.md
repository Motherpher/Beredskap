# Granskning och leveransgrindar
## Inför varje källregistrering
- [ ] Originalkälla identifierad, tidsstämplad och rättshavare/licens bedömd
- [ ] Publiceringsdatum och händelsedatum separerade
- [ ] Fysisk geografi, måttenheter, stationer och tidsfönster kontrollerade
- [ ] Fulltext/sida kontrollerad eller markerad PENDING
- [ ] Säkerhets-/personuppgiftsgranskning gjord

## Inför varje analys
- [ ] Ex ante-information skild från efterhandsinformation
- [ ] Befogenhet/rådighet identifierad för varje tänkbar åtgärd
- [ ] Alternativa förklaringar och motbelägg uppförda
- [ ] Tekniker, hydrolog, jurist eller annan sakkunnig anlitas där slutsats kräver sådan kompetens

## Inför publicering
- [ ] Varje kritiskt påstående har `claim_id` och källhänvisning
- [ ] Berörda aktörer beredda att bemöta centrala påståenden
- [ ] Rapport och artikel skiljs åt; stil får inte övertrumfa belägg
- [ ] Exakta sårbarhetsdetaljer om driftmiljö borttagna eller aggregerade
- [ ] Öppna frågor anges som öppna frågor
